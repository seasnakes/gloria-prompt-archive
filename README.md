# 光彩跃然 · 影像灵感库

SEASNAKE 的提示词与影像收藏站。首页延续蓝色 Three.js 流体、宋体标题、滚动字幕、打字机叙述和官方三角字标。

- 网站：https://seasnakes.github.io/gloria-prompt-archive/
- 来源：飞书「提示词作品库」的发布快照。
- 首次同步：2026-09-13，46 个作品，其中 1 条含原始提示词，45 条是效果参考。后续以网站同步时间及实际数量为准。

## 浏览

按关键词、风格、来源、模型和生成方式组合筛选，搜索覆盖全部记录。每次展示 12 个作品，点击「加载更多」继续。打开作品可播放视频、前后切换、查看来源、复制真实提示词及作品链接。收藏仅保存在当前浏览器；浅色和深色主题亦在本机保存。

没有原始提示词的作品明确显示「效果参考」，效果说明不会冒充提示词。未知模型和方式保留「待确认」。主页面滚出视口时会暂停 Three.js，以减少浏览画廊时的显卡占用；系统减少动态效果设置也会生效。

## 本地开发

需要 Node.js 22。

```sh
npm ci
npm run dev
```

本地预览为 `http://127.0.0.1:5182/`。构建验证：

```sh
npm test
npm run build
npm run preview
```

`preview` 在 5183 端口验证实际产物。GitHub Pages 使用相对资源路径，作品分享采用 `#work/作品ID`，直接打开无需服务器路由。

## 从飞书更新

飞书用于管理内容；公开网站展示最近一次发布的数据，**并非实时连接飞书**。在已登录 `lark-cli` 的本机执行：

```sh
npm run sync
npm run publish
```

同步以用户身份只读导出指定字段，检查完整分页、数量和附件，再原子替换网站数据。封面和视频以内容摘要命名保存到 `public/media/`，不会在网页中放置飞书临时附件地址。已有附件复用本机缓存；新增附件通过飞书官方 CLI 下载。推荐安装 `ffprobe`，以获取视频尺寸和时长。

默认表格位置在同步脚本中，可用 `FEISHU_BASE_TOKEN` 和 `FEISHU_TABLE_ID` 覆盖。表格位置标识不等于访问凭证。用户凭证继续由本机 `lark-cli` 管理，**不需要向 GitHub 配置飞书令牌**。

`publish` 先测试和构建，只提交公开数据与附件的改动，再推送 `main`。源码改动单独提交。GitHub Actions 自动构建并部署到 GitHub Pages。读取失败、数据不完整或附件缺失时停止更新，保留上次发布数据。

`.local/` 内的原始导出、附件令牌索引、下载缓存及 `.env` 均被 Git 忽略；这些文件不进入网站。发布字段限作品标题、原文提示词、效果说明、公共来源、创作元信息和媒体。个人收藏与飞书内部文档链接不发布。

## 版本记录与回退

每次内容发布和源码修改保留 Git 提交记录；首次完整站点标记为 `v1.0.0`。仓库 **Commits** 查看改动，**Actions** 查看构建与部署结果。要恢复某次修改之前的状态，使用 `git revert <提交ID>` 后推送 `main`，会留下回退记录并重新部署。不要只改 URL 中的版本数字。

本项目初版复用已验收的 Blue Tears V6 视觉引擎。旧的独立流体 V1–V6 预览不随本仓库发布；网站版本由提交和发布标签管理。
